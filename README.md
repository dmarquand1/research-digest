# Research Digest

A Python project for discovering, ranking and summarising newly published
scientific papers based on my research interests.

## Aim

The eventual tool will:

1. Search scientific literature databases for new publications.
2. Identify papers relevant to my research interests.
3. Rank papers by relevance.
4. Generate a weekly research digest.
5. Allow me to provide feedback to improve future recommendations.

## Status

Currently under development.

### Stage 1

Creating a structured research-interest profile.
